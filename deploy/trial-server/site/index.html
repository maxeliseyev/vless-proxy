Заметки о статическом анализе данных

Здесь собраны рабочие заметки по обработке таблиц, проверке выборок и построению отчётов. Записи появляются по мере того, как накапливается материал, без расписания.

Почему медианы, а не средние

Среднее чувствительно к одиночным выбросам: один неверно введённый ноль или лишняя цифра двигают его сильнее, чем десять обычных наблюдений. Медиана этого не замечает, поэтому для первичного просмотра данных она надёжнее. Среднее стоит показывать рядом, когда распределение уже проверено.

Проверка выборки перед отчётом

Перед тем как строить графики, полезно ответить на три вопроса: сколько строк потерялось при объединении таблиц, есть ли дубликаты по ключу, и совпадают ли итоговые суммы с исходником. Эти три проверки отлавливают большую часть ошибок, которые потом неловко объяснять.

Форматы хранения

Для небольших наборов достаточно CSV с заголовком и кодировкой UTF-8. Для таблиц от нескольких сотен мегабайт удобнее столбцовые форматы: они занимают меньше места и читаются по нужным колонкам, а не целиком.
